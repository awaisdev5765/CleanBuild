# CleanBuild Privacy Notice

CleanBuild works locally and does not require an account. It does not include analytics, advertising, tracking SDKs, telemetry, or a cloud backend.

The app reads known developer-tool cache/build locations and folders the user explicitly chooses. It stores only local metadata required for scan history, cleanup outcomes, workspace paths, exclusions, and preferences. It does not persist file contents.

Cleanup is never automatic. The user selects targets, reviews consequences, confirms the plan, and may keep dry run enabled. Protected and unsupported sources cannot be selected for generic cleanup.
