# UX Specification

CleanBuild uses `NavigationSplitView`, system materials, semantic colors, SF Symbols, Dynamic Type-compatible styles, native sheets and alerts, and a minimum 980×650 window. First launch explains privacy and scan scope without requesting blanket access. Scan progress names the active adapter without inventing a percentage. The explorer exposes exact canonical paths, measured sizes, safety labels, and consequences. Cleanup review keeps dry run enabled by default and requires an additional acknowledgement for Review items.

Keyboard commands: Command-N starts a scan, Command-R rescans, Command-F focuses search through the native searchable interface, and Command-comma opens Settings.
